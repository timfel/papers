- We provide an architectural overview of our Path Tools framework that
  provides debugging tools for our test-driven fault navigation.

- We present extension to the Path Tools framework - Peek-At-Talk - for
  debugging non-deterministic failures, that implements our record and
  refinement approach.

- We describe an implementation technique based in context-oriented
  programming that allows us to safely adapt core library code in a
  self-sustaining development environment.

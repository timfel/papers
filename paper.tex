\begin{abstract}
  Logic puzzles such as Sudoku are described by a set of properties
  that a valid solution must have. Constraints are a useful technique
  to describe and solve for such properties. However, constraints are
  less suited to express imperative interactions in a user interface
  for logic puzzles, a domain that is more readily expressed in
  the object-oriented paradigm.
  
  Object constraint programming provides a design to integrate
  constraints with dynamic, object-oriented programming languages. It
  allows developers to encode multi-way constraints over objects and
  object collections using existing, object-oriented
  abstractions. These constraints are automatically maintained at
  runtime.

  In this paper we present an application of this design to logic
  puzzles in the Squeak/Smalltalk programming environment. We argue
  that our implementation facilitates event-driven applications with
  constraints on different parts of the system, by moving the burden
  to maintain the constraints from the developer to the runtime
  environment.
\end{abstract}

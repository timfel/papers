\section{Introduction}

Sketch- and pen-based input 

Sketching and note-taking while thinking about a problem is a common task in
software engineering. User interfaces, objects, interactions, and even code is
sketched on whiteboards and on paper to present and discuss.

While pen-based input on digital devices are commonly used for interaction tasks
such as 3D modeling, note taking, or domain specific applications such as
calculators or musical notation tools. For specialized domains, some work has
been done to allow users to sketch controls to prototype user interfaces quickly
(Wong, SILK, Monet, ...). There has also been a long history of using pen-based
input for programming tasks, with the Sketchpad system by Ivan Sutherland
arguably the first to use pen-based gestures to express operations.

The contribution we are working towards is to allow users to sketch and script
graphical objects.

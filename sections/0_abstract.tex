% Motivation
The Lively Kernel is a self-supporting, browser-based environment for
explorative development of active Web content. 
In addition to object-oriented programming with modules and instances, Lively supports an object-centric approach to manipulate visible objects directly.
% Problem statement
However, to share behavior between similar objects, Lively developers must choose to either abstract concrete objects into classes, traits, or layers or
copy code to multiple objects. That is, they must choose either longer
feedback loops during development or redundancy which reduces
maintainability.

% Approach
In this paper, we propose an extension to the object-centric
development tools in Lively to work on multiple concrete objects. In
our approach, developers may dynamically group live objects that share
behavior and manipulate such groups as if they where single objects.
% Results and conclusion
Our enhancements scale Lively Kernel's explorative development
approach from one to many objects, while preserving the concreteness
and immediacy of working with specific, live objects.

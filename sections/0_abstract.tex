% Motivation
The Lively Kernel is a self-supporting browser-based environment for exploratively developing active Web content. 
It provides object-centric tools for directly improving concrete objects that live in wiki-like worlds.
Thereby, developers receive feedback on changes to specific concrete objects immediately.
% Problem statement
However, when multiple similar objects implement the same behavior, developers need to implement such functions repeatedly on concrete objects or in abstract types. 
That is, developers have to choose between unnecessary redudancy or prolonged feedback loops.

% Approach
In this paper, we extend Lively's object-centric development tools to work on multiple concrete objects.
Developers group live objects that play identical roles and improve whole groups as if they where single objects. 
% Results and conclusion
Our enhancements scale Lively's explorative development approach from one to many objects, while preserving the concreteness and immediacity of working with specific live objects.

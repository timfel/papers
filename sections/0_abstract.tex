% Motivation
The Lively Kernel is a self-supporting browser-based environment for exploratively developing active Web content. 
It provides object-centric tools for directly improving concrete objects that live in wiki-like worlds.
% Problem statement
This object-centric development approach provides immediate feedback on changes to specific concrete objects.
However, when multiple similar objects implement the same behavior, developers implement such functions repeatedly on live objects or once, but in an abstract type. 
That is, developers have to choose between unnecessary redudancy or prolonged feedback loops.

% Approach
In this paper, we extend the object-centric development approach to a work on multiple concrete objects of a specific role.

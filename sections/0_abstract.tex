% Motivation
The Lively Kernel is a self-supporting, browser-based environment for
exploratively developing active Web content. It provides
object-centric tools to directly manipulate concrete objects that live
in dynamic worlds. Such modifications are immediately visible and
developers receive feedback immediately. Additionally, Lively supports
further means to functional decomposition as well---classes, traits,
and layers.
% Problem statement
Developers must choose one of these decomposition
mechanisms. Abstracting from concrete objects reduces immediacy,
however, copying code to multiple objects leads to redundancy.

% Approach
In this paper, we propose an extension to the object-centric
development tools in Lively to work on multiple concrete objects. In
our approach, developers may dynamically group live objects that share
behavior and manipulate such groups as if they where single objects.
% Results and conclusion
Our enhancements scale Lively Kernel's explorative development
approach from one to many objects, while preserving the concreteness
and immediacy of working with specific, live objects.

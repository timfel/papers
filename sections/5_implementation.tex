\section{Implementation in the Lively Kernel} \label{sec:IMPLEMENTATION}

We evaluated our approach with a tool-based solution extending the
Object Editor of Lively. Our Object Editor allows to define groups
visually and programatically. It stores the group as property on all
group members and edits them simultaneously.

\paragraph{Defining Groups}

Our extended Object Editor, shown
in~\autoref{fig:group-editor}, supports all three
selection mechanisms of our approach: direct, scene-graph, and
programmatic selection.

\begin{figure}
  \centering
  \includegraphics[width=\linewidth]{images/group_editor}
  \caption{Extended Object Editor with scene-graph representation and
    object selection}
  \label{fig:group-editor}
\end{figure}

For the direct selection, the editor provides a tool~\textcircled{1}
to enter \emph{selection mode}, in which developers define groups by
clicking on the visual representation of objects. Furthermore, we
modified the edit button of Lively's selection tool to open our editor
on the selected morphs. To select from the scene-graph, we added a
tree-view~\textcircled{2} that shows the composition hierarchy of the
world. Developers can browse the scene and click to select. For
programmatic selection, we have modified the global function
\texttt{edit}, which opens an editor on the argument, to handle
collections of targets. In that case, the editor treats all targets as
a group. The global edit function is also invoked by Lively's
shortcuts, providing convenient access.

\paragraph{Saving Groups}
\label{sec:persisting-groups}

Defined groups are initially anonymous and transient. Naming a group
persists it. In our prototype groups are tags. When developers name a
group, the editor attaches the name to the group members. Lively
serializes this property as part of the object, thereby storing group
membership in the PartsBin. We collect groups available in a world by
iterating over visible objects. The editor offers the set of unique
group names~\autoref{fig:group-names} for access.

\begin{figure}
  \centering
  \includegraphics[width=\linewidth]{images/groups_selection}
  \caption{The list of available groups}
  \label{fig:group-names}
\end{figure}

\paragraph{Editing Groups}
\label{sec:editing-groups}

For a given group, the editor determines the common functions by
comparing their code and omits all others from its function
list. Whenever developers evaluate code in the editor's script pane,
we check the code for occurrences of \texttt{this}. If there is none,
the code is evaluated once, otherwise for each object in the
group. For group evaluations we guard each evaluation with a
\texttt{try/catch} statement. Similarly, saving a function executes
\texttt{addScript} on each object, effectively duplicating the
function.

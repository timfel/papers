\subsection{Object Group as an Object Property}
\begin{itemize}
 \item group-object is a second-class object (destroyed immediately after use)
 \item group membership is saved as an object attribute (like a tag)
 \item group membership serializes as usual, therefore its save/loaded in the PartsBin
 \item list of available group calculated through asking every object for its group membership
 \item so objects are listed in a group if they are currently loaded
 \item groups are listed only if any of its members is currently loaded
\end{itemize}

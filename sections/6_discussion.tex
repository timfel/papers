\section{Future Work} \label{sec:FUTURE_WORK}
% have lots of problem vs. solutions pairs

%problem:
- only group memberships/groups shown where corresponding objects exist in the world
- accidental overwrite of methods/properties possible
- in a group only similarities of objects are shown - not differences. maybe differences are as important as similarities and should be somehow shown
%solution:
automatically generated subgroups
 \begin{itemize}
  \item groups show similar behavior
  \item not similar behavior is parted into subgroups, which again group shared behavior
  \item this is a tree structure
  \item used to comprehend code (``oh this is a natural subgroup, lets name it!'')
  \item used to find diverging group members and eventually merge them
 \end{itemize}

 
%problem
- having an object its hard to tell which methods origin from which group and which are unique
%solution
- add group:<name> tags to methods to annotate that the method was last edited in context of that group
- if methods was edited in another group - replace annotation
- if group was edited outside of a group - delete annotation

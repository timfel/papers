We propose to extend Lively's object-centric development tools to work on object groups. 
Developers may group available objects that share behavior explicitly or implicitly.
They can select objects explicitly by clicking their visual representation or choosing them from a representation of the Morphic scene graph, while they can select objects implicitly by evaluating program statements.
The object-centric development tools then present the shared behavior and allow to add and alter further behavior to all group members. 
Further, developers may use groups to evaluate statements on all members of groups to propagate changes to all of them and simultaneously.

With our approach, tools automatically handle the duplication of code between objects, while the developer continues to interact with live objects.
That is, developers no longer choose between manual repitition of code of multiple objects, unnessary indirection in form of delegation or the extended feedback cycles of, for example, class-based functional decomposition.
